# 新手教程设计：滴滴代吵

## 设计结论

当前项目最适合采用“轻引导 + 首次任务”的新手教程，而不是长篇说明页。用户第一次打开时，应该先在 30 秒内完成一次“临时代吵”的接话成功，再引导TA创建“专属嘴替”，最后把“吵架训练场”作为进阶玩法解锁。

原因：

- `临时代吵` 当前是默认入口，信息最少，用户只需要提供场景、对方一句话和目标。
- `专属嘴替` 需要先有人格档案，上传 txt 对新人有门槛，应优先推荐“做测试题生成”。
- `吵架训练场` 配置项较多，适合在用户理解“主线、边界、强度”之后再进入。
- 项目定位强调“有气势，不越界；有逻辑，不内耗”，教程必须先建立安全边界，避免用户把产品理解成单纯攻击工具。

## 教程目标

1. 让用户知道三个核心功能分别什么时候用。
2. 让用户完成一次真实接话，获得即时反馈。
3. 让用户理解“目标、主线、边界、攻击力”四个关键概念。
4. 引导用户创建一个专属嘴替，并知道测试题是最低门槛路径。
5. 让用户知道记录、偏好、飞书接入在哪里，但不在首次流程里强制配置。

## 推荐教程结构

### 第一阶段：首次进入，3 张漫画贴纸说明

展示位置：首次访问任意页面时，覆盖在当前页面上方的轻量底部弹层。

交互形式：

- 只出现一次，可跳过。
- 使用当前漫画贴纸视觉：粗描边、黄色/粉色/蓝色贴纸、小进度章。
- 不把用户带到单独的“介绍页”，直接进入可操作页面。

文案：

1. `先别急着回。`
   `把对方刚说的话、你想要的结果告诉我，我先帮你守住主线。`

2. `攻击力不是越脏越强。`
   `这里的强，是更清楚、更稳、更不被带偏。`

3. `先从临时吵开始。`
   `不用建档案，30 秒体验一次“对方说一句，我帮你接一句”。`

主按钮：`开始临时吵`

次按钮：`跳过教程`

跳转：进入 `#/temp`。

### 第二阶段：临时代吵首次任务

展示位置：`TempArguePage`。

目标：让用户生成或填写一个临时冲突，并完成第一轮接话。

步骤：

1. 高亮 `换个场景` / `场景设置`
   提示：`没想好怎么写，可以先换个场景；有真实冲突，就点场景设置自己填。`

2. 高亮场景设置里的 4 个字段
   提示：`最重要的是这四件事：和谁吵、对方说什么、为什么吵、你想要什么。写短句也够用。`

3. 高亮 `攻击力`
   提示：`低=体面解释，中=有压迫感，高=更锋利。但都要守住“不人身攻击”的边界。`

4. 高亮底部输入框
   提示：`接下来每一轮只要输入“对方新一句”。如果你只知道自己想表达什么，就用“按我的意思”。`

5. 首次生成结果后，高亮回复气泡和 `看分析和备选`
   提示：`先复制稳妥版；想更强硬，再展开看备选。分析区会告诉你对方在怎么带节奏。`

完成条件：

- `temp.rounds.length >= 1`

完成反馈：

`你已经完成第一轮接话。下一步可以创建专属嘴替，让它更像你本人。`

主按钮：`创建专属嘴替`

次按钮：`继续临时吵`

### 第三阶段：专属嘴替创建

展示位置：`PersonaPage` 空状态或创建弹层。

目标：让用户拥有一个当前嘴替档案。

推荐路径：

- 首推：`做测试题生成`
- 次推：`上传 txt 蒸馏`

原因：

- 测试题只需要答 8 题，适合无准备的新用户。
- txt 蒸馏需要用户准备聊天记录，还涉及隐私脱敏，应作为高级入口。

空状态提示文案：

`想让回复更像你本人？先做一套 8 题测试。没有聊天记录也能生成一个能用的嘴替。`

测试题页面提示：

- 顶部：`选最像你的反应，不用纠结完美答案。最多可以空 1 题。`
- 提交前如果未答太多题，沿用当前逻辑提醒。
- 生成后提示：`已生成专属嘴替。现在把前情、对方刚说的话、你想表达的目标发给它。`

txt 蒸馏页面提示：

- 保留当前隐私提醒，并更突出：`上传前先删姓名、手机号、地址、学校、公司。`
- 首次引导建议用户先粘贴 10-20 句本人发言即可，不要求完整聊天记录。

完成条件：

- `proxyPersona.currentProfile` 存在，或 `proxyPersona.selectedPersonaId` 存在。

### 第四阶段：专属嘴替首次生成

展示位置：`PersonaPage` 有档案后的聊天页。

目标：让用户知道专属嘴替输入不是只填“对方一句”，还可以填前情和目标。

步骤：

1. 高亮 `创建 / 切换`
   提示：`以后可以在这里切换不同嘴替，比如“冷静本人版”和“阴阳怪气版”。`

2. 高亮输入框
   提示：`一次可以写三类信息：前情、对方刚说的话、你想表达什么。写得越具体，嘴替越稳。`

3. 高亮设置按钮
   提示：`这里调表达方式和强度。第一次建议用“像我本人 · 中”。`

4. 高亮生成后的 `发送飞书`
   提示：`如果配置了飞书群 Webhook，可以把生成结果推到群里。首次不需要配置。`

完成条件：

- `proxyPersona.chatTurns` 中出现至少一条 assistant 消息。

### 第五阶段：训练场进阶引导

展示位置：`TrainingPage` idle 状态。

目标：用户理解训练场不是立即代说，而是练习“自己怎么说”。

进入条件：

- 完成临时代吵第一轮，或完成专属嘴替首次生成后，再提示进入。

引导文案：

`训练场不会直接替你发言，它会扮演对手，帮你练习不被带偏。`

步骤：

1. 高亮 `AI生成一局训练`
   提示：`不知道练什么，就让系统先生成一局。`

2. 高亮 `本局角色`
   提示：`A/B 是冲突里的两方。你选一个角色练习，AI 自动扮演另一方。`

3. 高亮 `训练目标`
   提示：`第一次建议选“抓住核心问题”和“不情绪失控”。`

4. 高亮训练中 HUD
   提示：`上方会显示回合、目标和 AI 对手松动值。别只追求狠，分数会看逻辑、边界和风险。`

5. 高亮本轮反馈
   提示：`每轮结束后展开反馈，看逻辑、气势、边界、主线和风险。`

完成条件：

- `training.feedbacks.length >= 1`，或 `training.gameState === "finished"`。

### 第六阶段：收尾提示

展示位置：完成前三条主线之一后，在 `RecordsPage` 或底部 toast 中提示。

文案：

`这次记录已经放进“记录”。以后可以去“我的”调整默认语气、攻击强度和主线锁定。`

引导按钮：

- `查看记录`
- `调整偏好`

## 页面级教程优先级

首次新用户推荐顺序：

1. `临时代吵`：最高优先级，最快获得成功体验。
2. `专属嘴替`：第二优先级，形成留存资产。
3. `吵架训练场`：第三优先级，作为进阶功能。
4. `记录`：完成任务后再讲。
5. `我的`：只在用户主动点击或完成首次任务后提示。

## 交互原则

- 不使用全屏教学长文，避免打断。
- 每次只高亮一个操作点。
- 每个提示不超过两句话。
- 所有教程步骤都可跳过。
- 新手阶段默认推荐“中强度”，避免一上来鼓励高攻击。
- 每次生成后都提醒用户先看主线和风险，而不是只复制最狠版本。
- 对桌面端可高亮右侧上下文面板；移动端优先高亮顶部场景卡和底部输入栏。

## 建议新增状态

可使用 localStorage 保存教程进度：

```js
{
  seenIntro: true,
  completedTempFirstReply: false,
  completedPersonaProfile: false,
  completedPersonaFirstReply: false,
  completedTrainingFirstRound: false,
  skippedAt: ""
}
```

建议 key：

```js
"didi_argue_onboarding_v1"
```

## 建议实现方式

1. 新增 `src/controllers/onboardingController.js`
   负责读取、更新、跳过教程进度。

2. 新增 `src/components/OnboardingCoach.js`
   输出贴纸式提示、遮罩、高亮说明和操作按钮。

3. 在关键元素上增加稳定标记：

```html
data-tour="temp-generate-scenario"
data-tour="temp-settings"
data-tour="temp-input"
data-tour="temp-replies"
data-tour="persona-create"
data-tour="persona-test"
data-tour="persona-input"
data-tour="training-generate"
data-tour="training-goals"
data-tour="training-feedback"
```

4. 在 `App.render()` 末尾根据当前页面和教程状态渲染 `OnboardingCoach`。

5. 在已有行为完成后更新进度：

- `handleTempReply` 成功后标记 `completedTempFirstReply`。
- `createPersonaFromTest` / `saveDistillPersona` 后标记 `completedPersonaProfile`。
- `generateProxyReply` 成功后标记 `completedPersonaFirstReply`。
- `handleTrainingSubmit` 成功后标记 `completedTrainingFirstRound`。

## 推荐首版范围

首版只做 8 个提示点即可：

1. 首次 3 张说明贴纸。
2. 临时代吵：场景设置。
3. 临时代吵：输入框和两个发送按钮。
4. 临时代吵：回复气泡和分析。
5. 专属嘴替：测试题入口。
6. 专属嘴替：输入框和回复设置。
7. 训练场：AI 生成一局训练。
8. 训练场：本轮反馈。

这样实现成本较低，但能覆盖用户第一次理解产品的关键路径。

## 成功标准

- 新用户不看 README，也能在 1 分钟内完成一次临时代吵接话。
- 用户能说清楚三种模式的区别：临时救急、专属嘴替、训练练习。
- 用户知道“攻击力”不是越界攻击，而是更清楚地守住主线。
- 用户至少创建过一个嘴替档案，或知道可以通过测试题快速创建。
- 教程不会阻塞老用户，所有提示都能跳过并记住状态。
